## 模型与兼容性

- 当前可用模型为 GLM-5.3、GLM-5.3-Flash。
- 官方说明 GLM-5.2/5.1 的历史调用会转向 GLM-5.3，GLM-5-Turbo/4.7 会转向 GLM-5.3-Flash，因此历史名称不再作为独立可用模型列出。
- 原记录中的 Claude Code、Cursor、Cline、Roo、OpenCode、Codex 均在官方工具列表中。
- Anthropic 端点仍为 `https://open.bigmodel.cn/api/anthropic`；官方也列有 OpenAI Chat Completion 和 Response 接入方式。
- 套餐只能用于官方允许的工具与产品环境，不是供任意应用使用的通用 API 余额。

## 旧数据为何不能直接延期

原记录的 ¥49/¥149/¥469 与约 80/400/1,600 prompts 每 5 小时对应历史 V2 口径。官方老用户说明仍保留其适用资格，但它们不是当前新购积分套餐。原记录还把历史价格、prompt 配额与新版 credits 描述放在一起，容易误导新用户。

本次改为现售个人套餐口径，并在价格备注中明确 V1/V2 老用户另按官方权益说明处理。更新模型列表、预算适用说明、官方来源与实际复核日期。下一次复核按既有 30 天周期设为 2026-10-24；历史 changelog 和编辑评分不代表本次重新做过模型性能评测。
