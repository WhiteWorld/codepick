## Conclusions written into the articles

- This is a configuration checklist, not a buying guide. Login, billing, and pricing stay in the existing compare articles; dates in the 2026-05-19 announcement were re-checked today and still match.
- Back up first. Official docs do not say whether first-launch onboarding rewrites original Gemini files in place, so that is unknown.
- Quote each official page separately when they differ, especially MCP `url` / `httpUrl` / `serverUrl` / Streamable HTTP vs HTTP+SSE, and skill path tables on the migration page vs the skills / discovery pages.
- The official import sample output shows what the docs illustrate (commands converted to skills, an MCP server written to `mcp_config.json`, some components skipped). It does not prove what will happen on a reader’s machine.
- Partial parity (themes / experimental visual overlays) is documented, not tested.
- The official migration page has no one-click rollback command. `/rewind` and “overwrite settings.json with defaults” (for invalid JSON, a wrong type, or an unrecognized value) are not migration rollbacks. Restoring backup files is not the same as undoing keyring-side token migration; no official keyring rollback command is given, and none is invented.
- Commands, paths, and field names are taken only from today’s official pages. No invented flags.

## Unknown / not tested

- We did not install Antigravity CLI or Gemini CLI, did not run `agy` or `agy plugin import gemini`, did not log in, and did not migrate a real profile.
- Whether first-launch onboarding edits Gemini files in place, copies them, or only writes new Antigravity paths.
- Whether a given theme, experimental overlay, SSE/WebSocket server, or workspace skill actually works after the documented steps.
- Whether an old SSE URL works after only renaming the key to `serverUrl`, given the MCP page’s HTTP+SSE limitation.
- Whether Gemini CLI hook files are auto-converted. The announcement lists Hooks as a kept capability; the migration page gives no procedure.
- Runtime security, cost, performance, or “seamless upgrade” claims.
